## From Numbers to Management Insight

Variance analysis should go beyond identifying that actual results are different from budget.

A useful management review asks:

- What changed?
- Why did it change?
- Is the variance temporary or ongoing?
- Which business driver caused it?
- Does the forecast need to change?
- What action should management consider?
